# Security

## Supported versions

Fixes go into the next release; only the latest release is supported. Glimt is not 1.0 yet,
so there are no maintained older lines.

## Reporting a vulnerability

Please do not open a public issue. Report it privately on GitHub instead: the
[Security tab](https://github.com/thornbux/glimt/security) → **Report a vulnerability**.
Say what happens, with a file or the steps that show it if you can.

Glimt opens files from anywhere, so a picture made to crash it, to write outside where it
should, or to run a program counts: these are taken seriously and fixed first.

You will get an answer within a week, and credit in the release notes if you want it.
