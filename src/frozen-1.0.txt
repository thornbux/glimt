# What users' settings files and scripts name, frozen in 1.x (see "Frozen in 1.x" in
# AGENTS.md): the settings' keys, the values of the settings that take a name (those of
# config::NAMED in its order, because a value's place is the number it was written as before),
# the window state's keys, the --remote commands with the words of their choices and the exit
# codes, the keys of --remote info's lines, the command-line options, the actions a script may
# run, the %field% names of the templates, the keys of a theme file, the files Glimt owns and the
# group words of the sharing file. A line is never taken out or changed. New ones are
# added at the end, as the test frozen_names_are_kept in config.rs says. A name renamed after
# 1.0 keeps its line: a table of old names in the code maps it to the new name, which is still
# read, and the new name is added at the end. Before 1.0 the maintainer took out the old names
# of 0.74.0 to 0.80.0, and renamed or took out the names that the review of this file found
# misleading (0.96.0).
